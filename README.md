# Описание программы

Программа определяет взаимное расположение двух прямых, заданных уравнениями:


a1*x + b1*y + c1 = 0
a2*x + b2*y + c2 = 0


Возможны три результата:

- прямые пересекаются;
- прямые параллельны;
- прямые совпадают.

Если прямые пересекаются, программа дополнительно вычисляет координаты точки пересечения.

## Порядок работы программы

1. Подключается класс `Scanner` для ввода коэффициентов с клавиатуры.
2. Пользователь вводит коэффициенты `a1`, `b1`, `c1` первой прямой.
3. Пользователь вводит коэффициенты `a2`, `b2`, `c2` второй прямой.
4. Вычисляется определитель системы:


d = a1 * b2 - a2 * b1


5. Если `d` не равен нулю, прямые пересекаются.
6. Координаты точки пересечения вычисляются по формулам:


x = (b1 * c2 - b2 * c1) / d
y = (c1 * a2 - c2 * a1) / d


7. Если `d` равен нулю, проверяется, совпадают ли прямые.
8. Если коэффициенты пропорциональны, выводится сообщение `совпадают`.
9. В противном случае выводится сообщение `параллельны`.
10. Объект `Scanner` закрывается.

## Используемые элементы Java

- `Scanner` — ввод коэффициентов с клавиатуры.
- `double` — хранение коэффициентов и координат с дробной частью.
- `if ... else` — выбор варианта взаимного расположения прямых.
- Арифметические операции — вычисление определителя и координат.
- `System.out.println()` — вывод результата.

## Пример 1. Пересекающиеся прямые

Ввод:


1 -1 0
1 1 -4


Результат:


пересекаются.
Точка пересечения: (2.0; 2.0)


## Пример 2. Параллельные прямые

Ввод:


1 1 1
1 1 3


Результат:


параллельны.


## Пример 3. Совпадающие прямые

Ввод:


1 1 1
2 2 2


Результат:


совпадают.


## Математическая идея

Если определитель `d` не равен нулю, система двух линейных уравнений имеет единственное решение. Поэтому прямые пересекаются в одной точке.

Если определитель равен нулю, прямые либо параллельны, либо совпадают. Для различения этих случаев программа проверяет пропорциональность коэффициентов уравнений.
